## 7. W03：套利、成本與數量引擎

全部使用Decimal。買入成本必須按ask逐檔走book，不用midpoint、last trade或前端概率代替。
以相同淨支付份額q計算：
S1：q−C_yes(q)−C_no(q)−F(q)−X(q)−B(q)。
S2：q−C_A,yes(q)−C_B,no(q)−F−X−B，另算反向。
S3：恰好一個結果成立時，全YES支付q，全NO支付(n−1)q，再扣所有成本。
S4：用合法結算情境中的最小支付減成本，保留完整情境表。
S5統計或預測策略另列，不能宣稱固定支付套利。

先完成S1。S2～S4建成有明確輸入條件的後續能力，不阻擋S1產品化。
每筆費用保留來源、生效時間、進位與幣別；扣shares時調整淨數量。未知費率不可設0。
USD與穩定幣不得無條件視為同一支付，換匯及幣值風險顯式處理。
lot size、深度、最小額、每場資金與曝險限制共同決定q。
